# Jev for Images: 초고속·초저가 이미지 분류·검수 모델 (TypeSafe)

TypeSafe의 Jev가 이미지 입력(Jev for Images)을 지원한다. 글을 생성하는 모델이 아니라 선택지·점수·좌표 같은 구조화된 판단을 빠르게 내는 모델이라서, 이미지 대량 분류·검수에 맞는다. 아래 수치는 영상과 벤더 발표 기준이며 독립 검증은 제한적이다.

## 속도와 비용
- 영상 기준으로 기존 대형 모델(LLM)보다 최대 200배 빠르고 400배 저렴하다. 영수증 100장 분류·검수에 약 1센트, 도면·사진·스크린샷 900장 정리에 40초가 걸린다고 한다.
- (보충) 벤더는 4개 업무 평균 193.6배 빠르고 444.6배 저렴하다고 발표했다. 응답 시간은 70~500ms, 입력 가격은 100만 토큰당 $0.042이고 출력은 무료다.
- (보충) 독립 테스트(Every, 합성 문서 12개·결함 7개)에서는 중앙값 0.35초 vs 8.83초(약 25배 차이)였다. 결함은 Jev가 6개, 비교 모델이 7개 찾았다. 빠르고 싸지만 정확도는 약간 낮을 수 있다.

## Box: 문제 위치를 좌표로 검출
- 사진 속 배송 파손, 얼굴 위치, 제품 결함 같은 대상을 Box(경계 상자 좌표)로 돌려준다.
- 좌표가 나오므로 자동 크롭, 얼굴 추적, 결함 부위 표시처럼 후처리가 바로 이어진다.
- Box 기능은 영상에서만 확인했고 웹 자료에서는 찾지 못했다.

## 활용처와 한계
- 영수증 자동 분류와 한도 초과 감지, 배송 파손 자동 감지와 CS 분류, 숏폼 제작 시 얼굴 추적·자동 크롭, 수백 장 도면·서류 페이지 라벨링.
- (보충) 텍스트 생성, 요약, 다단계 추론에는 맞지 않고, 근거 설명이 필요한 고위험 판단에도 부적합하다. 스키마가 맞는 답이어도 틀릴 수 있다.
- (보충) 입력은 약 32,000~64,000 토큰 범위로 제한된다는 자료가 있다(출처마다 다름). 응답 시간은 SLA가 아니다.

## 내 작업에 적용
- simAI 같은 AI API에서 분류·라우팅 단계는 이런 경량 모델로 두고, 어려운 추론만 상위 모델로 넘기는 구성을 비교해 볼 수 있다. 우리 데이터로 정확도와 지연 시간을 직접 측정한 뒤 정한다.
- 건축 도면 페이지 자동 라벨링처럼 이전 경력과 이어지는 데모 소재로 쓸 수 있다.
