- 채팅 목록/채팅방에 알림끄기·상단고정·나가기 기능 추가

- 내가 올린 나눔 게시글 수정/삭제 기능 추가

- 테스트 결과 화면 상단 5단계 아이콘 행 제거
- 반려식물 테스트 문항 수 표기를 7개에서 실제 8개로 수정

## 6. UI 아이콘/라벨 통일 (13:09 ~ 13:19)

- 게시글 수정 화면이 뒤로가기 히스토리에 막다른 항목으로 남지 않도록 수정
- 채팅 목록의 고정/알림끄기 표시를 이모지 대신 아이콘으로 정리
- 게시글 상세 조회수/채팅수 라벨을 기존 좋아요(♡)와 같은 기호 표기로 통일

## 7. 마무리 기능 보강 (13:32 ~ 13:38)

- AI 등록 탭 제목 크기를 탐색 탭과 동일하게 통일
- 탐색 탭 검색창을 실제 입력·필터링되는 기능으로 수정
- 게시물 상세의 관심/조회/채팅 표기를 탐색 카드와 동일한 SVG 아이콘으로 통일
- 보유식물 상세에서 사진을 다시 등록할 수 있는 수정 기능 추가
- 온보딩에서 입력한 닉네임이 저장되지 않아 서비스 전반에 반영되지 않던 문제 수정
- 마이페이지에서 반려식물 테스트 진입 후 뒤로가기 시 항상 홈으로 이동하던 문제 수정 (히스토리 기반 뒤로가기로 전환)
